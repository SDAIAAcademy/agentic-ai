Build agents that work, and the systems around them: LLM APIs and the agent loop, context engineering, harnesses, loops and graphs, then security, evaluation and production. With free open models over OpenRouter and Hugging Face.

AI Engineering Track 4 teaching days × 4h + capstone day 16 hands-on labs in Python Free API models only

One case study, all week

Madar Municipal Services is a fictional municipality that issues building, renovation, signage, food-truck and event permits. Participants build Rafeeq (رفيق), its bilingual permit assistant, and the systems around it: tools over three API shapes, retrieval over ten bilingual policies, memory and skills, an MCP server, a harness with permissions, a Ralph loop that fixes code, an eval suite, a review graph with a human gate, an A2A worker, an attack and its defence, and an HTTP service with traces. All data is synthetic.

Capstone

Individually or in pairs, build a working agent system on one of three tracks:

  • Rafeeq in production: the Madar assistant as a complete service with MCP tools, memory, approvals, security, evals and an API
  • Your harness: a domain harness for a real workflow in your entity, with context files, permissions, a loop and evals
  • Graph workflow: a durable, human-in-the-loop process as a graph with agents inside nodes

Minimum: 3+ tools (one over MCP), a context file plus memory or retrieval plus a compaction or budget rule, an approval on a write action with step and cost budgets, 15+ eval tasks on two configurations with an error analysis, and a security note (trifecta, one attack, one defence). Starter kit: labs/capstone/.

Rubric

Working system and live demo25%
Context and harness engineering decisions25%
Evaluation and error analysis20%
Security, governance and operability20%
Presentation and reproducibility10%

Participants will be able to

  • Call LLMs through the Chat Completions, Responses and Messages APIs, and write the agent loop over all three
  • Design tools and context deliberately: budgets, compaction, retrieval, memory, skills and MCP
  • Take a harness apart (Pi, OpenClaw, Hermes, Mercury) and add permissions, hooks and budgets to their own
  • Choose between building on an SDK, a hosted agent runtime or their own loop
  • Run agents in outer loops and as graphs with human gates, checkpoints and many agents
  • Evaluate agents with graders, judges and pass^k, secure them against injection, and ship them as a traced service

Setup

Audience: Python developers and ML or data engineers who have called an LLM API. No prior agent framework experience needed.

Environment: any laptop CPU with uv, or Google Colab. All model calls go to free API models (an OpenRouter key; a one-time 10-credit top-up raises the free quota from 50 to 1,000 requests a day). Node.js 22.19+ is optional, for the Pi teardown. Run 00_setup_check before Day 1; see labs/README.md.

Stack: openai · anthropic · openai-agents · OpenRouter · Hugging Face · Pydantic · model2vec · bm25s · mcp (SDK v2) · LangGraph · a2a-sdk · FastAPI · OpenTelemetry · Pi · PEP 723 scripts with uv run.

Choosing models: Artificial Analysis, LMArena, BFCL, τ²-bench, Terminal-Bench, and then your own eval.
